** Please be patient while the chart is being deployed **

List all helm chart releases with:

    helm list

To check if everything is installed successfully, make sure the following resources show "Ready" as true, it will take some time initially

    kubectl get ksvc -n {{ .Release.Namespace }}

Check the running pods with:

    kubectl get po -n {{ .Release.Namespace }}

To uninstall hzp-qa-svc subchart and all its dependency:

    make uninstall NAMESPACE={{ .Release.Namespace }}
